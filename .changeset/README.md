# Changesets

Этот каталог хранит [changesets](https://github.com/changesets/changesets) — описания изменений публичного API библиотеки.

## Как добавить changeset

1. Внесите изменения в код.
2. Выполните `npm run changeset`.
3. Выберите затронутые пакеты и уровень версии (patch / minor / major).
4. Опишите изменение — оно попадёт в changelog.
5. Закоммитьте созданный markdown-файл из `.changeset/` вместе с кодом.

## Уровни версий (SemVer)

- **patch** — исправления багов, не затрагивающие публичный API;
- **minor** — новая обратно совместимая функциональность;
- **major** — несовместимые изменения публичного API.
